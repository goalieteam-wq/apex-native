APEX — нативное приложение (Этап 1: каркас)
=============================================

Что внутри:
- www/            — само приложение APEX (тот же файл, что на вебе, + нативные напоминания)
- ios/            — готовый Xcode-проект (Capacitor 8, Swift Package Manager)
- ЗАПУСК.command  — двойной клик: ставит зависимости и открывает Xcode
- capacitor.config.json — настройки оболочки (id: ru.goalieteam.apex, имя: APEX)

Что уже настроено:
- Иконка и заставка — из эмблемы клуба, фон #0f0f12
- Поворот экрана заблокирован (только вертикальный)
- Статус-бар: светлый текст под тёмную тему
- 🔔 Напоминание в Профиле: ежедневно в выбранное время, работает на закрытом экране
- push-плагин уже встроен (пригодится на Этапе 4 — умные уведомления)

Порядок запуска на Mac (первый раз):
1. Установить Xcode из App Store (самое долгое — 10+ ГБ)
2. Установить Node.js LTS с nodejs.org
3. Двойной клик по ЗАПУСК.command
4. В Xcode: подписать командой и запустить на своём iPhone
   (бесплатно, без платного аккаунта — приложение живёт 7 дней, потом перезапустить)

В приложении один раз: войти тем же аккаунтом (данные подтянутся из облака)
и заново вставить ключ ИИ в Профиле — ключ сознательно не хранится в коде.
